# 🍎 水果影像辨識系統 Fruit Recognition

從白底資料集到真實照片：**影像分類（A）＋物件偵測（B）** 的訓練、測試與整合。

- **線上 Demo**：https://huggingface.co/spaces/PCChen27/Fruit_Recognition_Free_GPU
- **技術**：PyTorch、ResNet18、MobileNetV2、YOLOv8s、Gradio
- **簡報**：`水果影像辨識_作品集.pptx`

> Demo 使用 ZeroGPU，第一次辨識或排隊時可能較慢。

---

## 研究動機

公開水果資料集多半是白底、單顆水果，但真實照片可能有水果堆疊、遮擋、複雜背景與不同光線。

本專題建立兩種模型：

- **A 分類**：判斷照片中的水果種類
- **B 偵測**：框出水果的位置、種類與數量

並使用真實照片與圖庫照片，檢查模型從白底資料集走向真實場景時的表現差異。

---

## 模型與資料

| | A 分類 | B 偵測 |
|---|---|---|
| 模型 | Baseline CNN、ResNet18、MobileNetV2 | YOLOv8s |
| 資料 | Fruits-360 | Zenodo 水果偵測資料集 |
| 類別 | 55 類 | 26 類水果 |

B 偵測模型新增奇異果、覆盆子、黑莓、哈密瓜、菠蘿蜜等類別。

---

## 主要結果

### A 分類

ResNet18 真實照片 Top-1：

**15.5% → 66.0%**

加入真實照片訓練後，模型在真實場景的辨識能力明顯提升。

### B 偵測

新模型在資料集 test：

- **mAP@0.5：0.772**
- **Precision：74.0%**
- **Recall：75.9%**

在 150 張真實與圖庫照片中，至少框到一個正確種類的比例：

**64% → 72%**

但框得更多的同時，錯誤框也增加，因此沒有單純以「框越多越好」作為最佳設定。

## Gradio 介面

- **一般模式**：上傳照片後直接辨識。
- **研究模式**：可調整信心門檻、圖片大小與實驗設定。

A 分類回答「**是什麼水果**」，B 偵測回答「**在哪裡、有幾顆**」，兩種模型整合於同一個 Gradio 介面。
